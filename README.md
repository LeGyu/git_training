# git_training — 简易计算器

C++ 实现的四则运算练习项目，用于练习 Git 的分支创建、合并与远程协作。

## 功能说明

支持 `+`、`-`、`*`、`/` 四种运算：输入两个操作数和一个运算符，程序调用对应的运算函数并输出结果。除法会检查除数为 0 的情况。

## 项目结构

| 文件 | 说明 |
|---|---|
| `calc.h` | 四个运算函数的声明 |
| `main.cpp` | 程序入口：读取输入、按运算符分发、打印结果 |
| `add_sub.cpp` | `add` / `sub` 的实现（add-sub 分支） |
| `mul_div.cpp` | `mul` / `div` 的实现（mul-div 分支） |

## 编译命令

需要支持 C++11 及以上的编译器（MinGW-w64 的 g++ 或 MSVC）。

```bash
g++ -o calc main.cpp add_sub.cpp mul_div.cpp
```

## 使用方法

编译后运行：

```bash
./calc
```

按提示输入表达式，格式为 `操作数 运算符 操作数`：

```
请输入表达式（格式：操作数 运算符 操作数，例如 3.5 + 2）：
3.5 + 2
3.5 + 2 = 5.5
```

若除数为 0 或运算符不在 `+ - * /` 之内，程序会输出错误信息并以非零状态码退出。

## 运行环境

- Windows + Git Bash（或任意 POSIX 终端）
- g++ (MinGW-w64) 或 MSVC
